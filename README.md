<h1>TIC-TAC-TOE</h1>
<p>
  <strong>Tic-tac-toe </strong>(also known as noughts and crosses or Xs and Os) is a classic two-player strategy game. The game is played on a 3x3 grid, where players take turns marking empty squares with their designated symbol—traditionally an X or an O. 
</p>
<p>
<h2>How to Play</h2>
  <ul>
    <li>
      <strong>Objective:</strong> Be the first player to place three of your marks in a horizontal, vertical, or diagonal row.
    </li>
    <li>
      <strong>Turns:</strong> "X" typically goes first, alternating turns with "O" until someone wins or all squares are filled.
    </li> 
    <li> 
      <strong>Tie Game:</strong> If all 9 grid spaces are filled and neither player has achieved a row of three, the game ends in a draw (or "cat's game").
    </li>
  </ul>
</p>
<p>
  <h2>
  Basic Rules Summary
  </h2>

  <ol>
    <li> 
      The game is strictly turn-based; you can only place one mark per turn.
    </li>
    <li>
      You cannot overwrite a square that has already been marked.
    </li>
    <li>
      Tic-tac-toe is a mathematically solved game. If both individuals play perfectly, the match will always result in a tie.
    </li>
    
  </ol>

</p>
